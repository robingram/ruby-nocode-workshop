## Sample app

Build your own app idea or uase this sample:

### Music player

* The app holds a library of songs.
* Each song has:
  - Title
  - Artist
  - Release title (e.g. the album it came from)
  - Genre
  - Duration
  - Release date
* A non-logged in user can:
  - Browse the library
  - Search by artist, title or release title
  - Browse public playlists
* A logged in user can:
  - Play songs (simulate 30s of "playing") and pause playing songs
  - Create playlists
  - Add a song to a playlist
  - Make a playlist public or private
